# UniXNU-sm4350-common

Shared UniXNU support for the Qualcomm SM4350 (holi): Kryo 460 (2x Cortex-A76 + 6x Cortex-A55, **no PAC**),
Adreno 619, UFS 2.2 and an RPM (SMD over GLINK) power controller.

First device: moto g53 5G (penang), `UniXNU-penang`. Status: device tree skeleton (CPUs, GICv3, UFS, GPU, display
blocks, disabled until their drivers are ported from the penang XNU port).
